# Request to the NCL ISBN centre for pre-2024 book data

Why this exists: 臺灣出版新書預告書訊 (data.gov.tw dataset 6730) is published as a
rolling twelve months. Older monthly files stay on isbn.ncl.edu.tw for a while
after they drop out of the listing — probing found every month from 2024-01
still served and nothing before it — so 2023 and earlier are unavailable by any
URL. That is a publishing policy, not a technical limit: the ISBN centre holds
the whole series. So the way to get it is to ask.

Contact, from the dataset's own metadata:

- 陳小姐 — isbn@ncl.edu.tw — 02-23619132 #728

Not sent by Claude. Review it, put your own name and contact at the bottom, and
send it yourself.
